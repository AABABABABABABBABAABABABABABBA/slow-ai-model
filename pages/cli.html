Each download requires your license key in the Authorization: Bearer header. The server streams the signed binary from Cloudflare R2 after verifying the license is active.

3. Install & run

macOS / Linux:

chmod +x chadcode
xattr -d com.apple.quarantine chadcode   # macOS only, first run
export CHADCODE_LICENSE='chad-xxxx-xxxx-xxxx-...'   # from step 1
./chadcode

Windows (PowerShell):

$env:CHADCODE_LICENSE='chad-xxxx-xxxx-xxxx-...'
.\chadcode.exe

First run binds the license to this machine's hardware fingerprint. The CLI caches a signed offline token for 24h so flaky networks don't block you. Subsequent runs on OTHER machines will be refused — generate a separate key or revoke + re-bind.

Security

  • Hardware binding: license locks to machine-id + MAC + CPU + arch on first run
  • Signed updates: the auto-updater verifies ed25519 signatures over the SHA-256 of each release — a tampered binary is refused
  • Single API host: all backend workers are hidden behind chadgpt-api.corbyiscool.workers.dev; the binary leaks no per-service URLs
  • Offline tokens: 24h cached verification so a dropped connection doesn't stop you working; past that, the CLI must re-verify
  • Instant revocation: compromised keys are killed from the founder panel; the client's next verify refuses
